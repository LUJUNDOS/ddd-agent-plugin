# no-fake-test —— 测试真实性闸

## 触发
- 写测试、声称"测试通过"、verify 核验证据前。

## 假测试判 FAIL 的清单（命中任一即拒）
1. **同义反复**：断言的前提由测试自身构造为真（如先 set 再 assert 同值）。
2. **反向断言**：预期错误路径却 assert "无异常"，或预期成功却捕获异常不报。
3. **只测顺路径**：DoD 含边界/错误/并发，测试却只跑 happy path。
4. **mock 被测物**：mock 掉正在测试的函数/模块再对其断言（测的是 mock 不是代码）。
5. **静默跳过**：测试被 skip/xfail 仍计入"绿"，或断言恒真（`assert True`）。
6. **不触真路径**：测试名含被测逻辑但从未执行真实代码（如直接 return 固定值）。

## 程序
- 扫测试源码，逐条对照上述清单。
- 命中 → 退回重写，标注哪条违反；不允许"先绿了再说"。
- 仅在真实覆盖 DoD 全部关键路径（含至少一条非顺路径）时才算真绿。

## 纪律
- 测试数量 ≠ 质量；一条真边界测试胜过十条顺路径测试。
- 不得为过闸而删/改测试使其变宽松。
