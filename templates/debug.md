# debug —— 调试纪律

## 触发
- 修复失败测试、诊断运行时错误、定位异常行为。

## 规则（验收标准）
1. **假设上限 3**：同时存活的假设 ≤ 3 个；超出先收束再继续。
2. **负面记录**：每次失败必须记录「被否假设 + 原因」，不得重复已被否的改法。
3. **3 连败即停**：同一问题连续 3 次失败 → 停止盲修，升级给用户重审设计/需求，不试第 4 次。
4. **读码优先**：优先读代码/加观测（日志、断点、最小复现）定位，而非随机改代码猜。

## 判违规
- 第 4 次盲目试同一类改法。
- 失败后不记录原因直接换法（无负面知识沉淀）。
- 假设堆叠超过 3 且不收敛。

## 纪律
- 停滞检测（三道刹车之一）触发 → 升级用户，不空转。
- 修法若被采纳，按 memory-protocol 记忆规程沉淀为经验（error/decision/insight 三类，≥3 次或显批升长期记忆）。
